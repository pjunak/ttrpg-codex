# Add-on API documentation

This folder is the public add-on contract for outside developers.
[AUTHORING.md](AUTHORING.md) is the guide, [API_V3.md](API_V3.md) the reference.
Keep both in sync with `contracts/addons/v3/`, `sdk/go/workerrpc/` and the
browser SDK in `frontend/src/addons/` whenever one of them changes, and describe
only what the host actually implements.
